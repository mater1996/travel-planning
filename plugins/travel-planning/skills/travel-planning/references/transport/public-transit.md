# 公共交通

## 何时读取

采用地铁、公交、有轨电车、公共轮渡、机场巴士或景区官方接驳时读取。长途客运和跨海船班读取 `coach-ferry.md`。

## 前置输入

- 准确起点出口、终点入口、预计出发时间和下一硬时间。
- 行李、儿童、老人、轮椅或步行限制。
- 适用日期是否为工作日、周末或节假日。

## 研究内容

1. 路线：线路名称、方向、上车站、下车站、换乘站和准确出口。
2. 运营：首末班、班距、运营日、临时调整和停止进站时间。
3. 票务：票价、购票或乘车码、实名要求与现金/境外卡限制。
4. 站内：步行距离、电梯、无障碍路径、大件行李和拥挤风险。
5. 末端：出站到目的地入口的步行、过街、坡度或接驳。
6. 备选：错过末班、设备停运、严重拥挤或大件行李无法执行时的出租车或其他路线。

## 结构化产出

- 每段写入 `transport_edges[]`，保留准确端点、线路方向、换乘、步行、等待和门到门时间。
- 关键站口写入 `route_anchors[]`，包含名称、地址或坐标、入口/出口说明。
- 动态首末班或临时调整写入 constraint/unresolved，并带适用日期和复核时间。

## 完成门槛

- 旅行者能知道从哪个口进入、在哪换乘、从哪个口出来。
- 时间包含步行、等候和换乘，不把车上时间当门到门时间。
- 行李和无障碍要求经过实际路径核验。
- 夜间或末班边界有明确替代方式和触发条件。
