# 页面交互与降级

## 何时读取

修改视图切换、筛选、折叠、餐厅轮播、地图懒加载、全屏、复制动作或外链行为时读取。

## 视图与筛选

- 详细行程、一览和路线图切换必须即时、可逆，不改写行程数据。
- 支持 Tab 与左右方向键，保持可见焦点与正确选中状态。
- 提供“只看待预约”“只看交通”“只看付费项目”等筛选；清除筛选后恢复完整顺序。
- 折叠只能隐藏补充内容，不能隐藏开放、预约、入口、交通、核心费用和失败备选。

## 渐进增强

Vue 源码由 `web/` 经 Vite 编译，CSS 与 JavaScript 内联进单一 `itinerary.html`。脚本不可用时：

- 顶部控件退化为纯 CSS 单选并仍可切换三个视图；
- 所有核心内容静态可读；
- 地图保留 HTTPS 外链；
- 不依赖同目录脚本、样式或运行时服务。

编译目标不能保留会让旧微信 WebView 整段解析失败的语法。微信附件预览可能完全禁用脚本，不能把 Vue 编译等同于附件内完整交互保证。

## 餐厅与复制动作

- 横向备选列表支持触控、滚轮/触控板与键盘聚焦；卡宽稳定，候选增加时不压缩。
- 折叠状态有明确 aria-expanded；收起后仍看得到门店名、主状态和重新展开入口。
- 只有公众号名而无可打开官方说明时，复制公众号名并提示在微信内搜索与进入菜单；复制失败时文本仍可手选。

## 地图

- 中国境内普通交通段：桌面使用 `ditu.amap.com/dir`；不含途经点的移动驾车段可使用移动导航页。
- 每日完整路线始终使用能保留 `via[n]` 的桌面路线 URL，移动端不能降级为丢途经点的简化链接。
- iframe 接近视口时只加载一次，加载后停止观察，不因滚出视口卸载或重复导航。
- 默认地图约 300px 桌面高度、240px 窄屏高度，并提供宿主页自己的全屏按钮。
- 全屏时卡片铺满视口，允许 Esc 退出；不支持 Fullscreen API 时在新标签打开设备对应路线。
- iframe 失败时核心站点顺序和外部路线链接仍可用。

## 外链与安全

外部链接新窗口打开并使用安全属性。标签写明平台与目标；地图入口不能描述为预订证明。没有用户单独授权时，页面不自动发起预订、付款、发布、互动或订单变更。

## 打印

打印入口不伪装为云端导出。打印样式隐藏交互控件、iframe 与非必要阴影，展开执行所需内容，并保持日期、事件和表格语义。
