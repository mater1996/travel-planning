# 兼容文档入口

本目录只帮助旧 assignment、旧书签或迁移说明找到新的权威文件，不承载业务规则。新任务不得把这里的文件写入 `required_guides`。

| 旧文档名 | 新入口 |
| --- | --- |
| [planning-pipeline.md](planning-pipeline.md) | `core/`、`orchestration/`、`workspace/` |
| [research-workflow.md](research-workflow.md) | `attractions/`、`transport/`、`dining/`、`lodging/` |
| [restaurant-research.md](restaurant-research.md) | `dining/index.md` |
| [source-strategy.md](source-strategy.md) | `core/evidence-policy.md` 与 `tools/` |
| [trip-readiness.md](trip-readiness.md) | `core/readiness.md` 与专项领域规则 |

兼容文件只保留一个迁移周期。使用方应更新到新入口；机器注册表、SKILL 主流程和新 assignment 都不能依赖本目录。
