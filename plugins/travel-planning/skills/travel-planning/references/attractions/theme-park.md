# 主题乐园

## 何时读取

采用主题乐园、水乐园或项目、演出和排队策略会显著改变日程的大型游乐场所时读取。

## 专项研究

- 开园、闭园、提前入园、检票与安检规则。
- 核心项目的身高、年龄、健康、陪同和随身物品限制。
- 预约通行、虚拟排队、快速通行或单人通道的适用规则与费用。
- 用户最重视项目、演出和巡游的优先级，不罗列全部设施。
- 园区分区、移动时间、排队波动和演出场次之间的依赖。
- 午晚餐窗口、园内候选、饮食限制和高峰排队。
- 项目关闭、预约失败、天气影响和闭园后疏散交通。

## 结构化要求

- checkpoints 按可执行顺序绑定项目或演出、预计时段、前置条件与可跳过性。
- 固定场次保留最晚到场与入场缓冲。
- 动态排队不作为提前规划的确定事实；页面展示策略与复核入口。
- 费用区分快速通行、单项体验与基础门票。

## 完成门槛

- 核心项目符合实际人群限制。
- 固定演出、餐窗和移动不会发生结构性冲突。
- 至少有一套核心项目关闭或排队失控后的替换顺序。
- 闭园后的返程或住宿接驳已落实。
