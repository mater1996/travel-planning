# 演出与夜游

## 何时读取

采用剧场演出、音乐会、固定场次表演、夜游船、灯光秀或需要夜间观景位置的活动时读取。

## 专项研究

- 演出或活动日期、场次、时长、语言、座区或观景位置。
- 开票、实名、取票、安检、停止入场和迟到入场规则。
- 场馆入口、座位到达时间、寄存和散场出口。
- 户外夜游的天气、风、能见度、停航或取消条件。
- 散场人流、末班公共交通、打车上车点与步行安全。
- 儿童年龄、噪声、着装或其他入场限制。
- 取消、改期、迟到或错过末班后的退款与返程备选。

## 结构化要求

- checkpoint 或事件保存固定开始、建议到达、停止入场和结束时间。
- `reservation` 或 booking task 保存票种、场次、人数和官方购票入口。
- 散场交通单独形成 `transport_edge`，不能用“结束后回酒店”代替。

## 完成门槛

- 场次和入场缓冲与前一活动可同时满足。
- 散场后的交通与住宿到达有主方案和至少一个备选。
- 户外活动有天气取消的复核入口和替代安排。
- 未购票时保持候选或待预订状态，不写成已确认席位。
