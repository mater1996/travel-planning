# 大型景区

## 何时读取

景点存在多个入口、大片分区、景交车、索道、观光车、游船或显著内部换乘时读取。单一入口、短距离步行景点只用景点入口契约。

## 专项研究

- 比较各入口与住宿、前后活动和离开交通的门到门差异。
- 分区开放、入口售检票、停止入园与各内部设施停止运营时间。
- 景交、索道、观光车或游船的线路、站点、方向、票种和排队风险。
- 入口到出口的完整 checkpoint 顺序，以及每段步行或内部交通。
- 基础票、必须景交、可选索道和互斥套票的费用边界。
- 饮水、卫生间、餐饮、休息和紧急退出点。
- 设施停运、局部分区关闭或时间不足时的缩线、换入口或退出方案。

## 结构化要求

- `entrance` 与 `exit` 分开保存，不能默认原路返回。
- 内部交通作为 checkpoint 或受控子结构，写清上车点、下车点和方向。
- `cost_items[]` 区分基础门票、必需交通和可选体验。
- 每个分区或设施的动态状态绑定适用日期和来源。

## 完成门槛

- 入口选择有路线依据，导航能落到实际可进入位置。
- checkpoints 从入口连续到出口，内部换乘不会断链。
- 最晚离开时间考虑内部设施停运和出口到下一事件的路程。
- 景交或索道停运时仍有可执行缩线或取消规则。
